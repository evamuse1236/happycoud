# Architecture

The Vite development middleware serves the local expanded archive through `/api/comments`. `scripts/comments.mjs` adapts reviewed snake_case fields, supplements them with the original snapshots using a relaxed filter, excludes the owner by both flags and author identity, joins replies only to known parents, derives provisional mood labels, and hashes the normalized result. The build writes an ignored static snapshot under `public/data/`. The browser also accepts the reviewed JSON directly.

`layout.js` packs every complete comment into the KHUSHI mask once per collection. Node geometry is immutable across zoom, mood, hover and resize. An arrival-only star pass uses temporary projected positions, settling at those nodes before revealing text at its fixed location. WebGL and Canvas2D share this timeline. `renderer.js` draws WebGL text atlases; `canvas-renderer.js` provides a Canvas2D fallback using the same geometry. Camera and gesture logic live in `math.js` and `controls.js`.

`main.js` coordinates the collection, cloud, filters, search, reading history, saved marks, and sound. `immersion.js` owns the expanded reading transition. It preserves whitespace as text nodes and wraps words in spans, maps the selected node's projected position to those spans, and plays a bounded Web Animations sequence. A Canvas2D burst settles into a static field. Closing, resizing, hidden documents, and reduced-motion changes cancel animation work. Each entrance animates at most 90 visible words and 112 particles.

The full-screen semantic dialog protects reading focus and retains Escape/close behavior. The exact comment remains selectable HTML. Its thread is expanded by default; related comments come only from the same post or author and exclude the current thread. There are no generated continuation texts.

`tools/build.mjs` creates a standalone directory and an offline single HTML containing the current local snapshot. Both are ignored outputs. Synthetic fixtures live only under `tests/fixtures/`. The old ZIP installer, duplicate local server, obsolete demo-based browser suites, and bundle-review watcher were retired after integration; Vite and the current test command are the canonical workflow.

`flow.js` owns short cancellable control and list transitions. The sound engine synthesizes its own cues after opt-in, with a 12-voice cap and rate limits. Sparse notes follow arriving stars; the resolving chord starts at the final star-to-word phase. Reader, mood, list, search, saved-mark and camera events use distinct cues. Hidden tabs and muted sound cancel pending voices.
